ACE Commands

Every command the ACE server registers, grouped by the access level needed to run it. In-game you type @ or / before the name — either prefix is stripped. Through the remote console (ace-cmd.sh) you type no prefix at all, and anything needing a character in the world is refused.

321 commands across 6 access levels. 111 can be driven from the remote console; the other 210 need a logged-in character on a landblock. Descriptions are ACE's own except for 7 that document themselves nowhere.
